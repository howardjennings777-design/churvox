# Churvox Launch Done Matrix

The launch path that matters:

1. Owner signs up.
2. Owner completes business profile, GST, first client, first job.
3. Owner invites worker.
4. Worker receives assigned job.
5. Worker acknowledges, starts, pauses/resumes if needed, adds notes/photos, completes.
6. Owner sees work proof in Command.
7. Owner approves or sends back.
8. Invoice draft is created/reviewed.
9. Owner sends invoice with PDF attached.
10. Customer receives PDF, opens public invoice link, pays or follows payment instructions.
11. Owner sees payment/overdue status.
12. Accounting sync comes after this core loop is proven.

Do not call launch ready until this flow passes on desktop and phone.
