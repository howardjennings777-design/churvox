# Churvox Real Test Plan

Real testing still required before launch.

## Owner test
- Sign up as a new owner.
- Verify email.
- Add business details, GST, logo and payment details.
- Add first client.
- Create first job.
- Invite worker.
- Open Command and confirm live backend mode.

## Worker test
- Login as worker.
- Confirm only assigned jobs are visible.
- Acknowledge job.
- Start, pause, resume and complete job.
- Add note and photo.
- Send Contact office message.
- Confirm owner sees Worker message slip in Command.

## Customer/public test
- Send public quote.
- Accept and decline quote links.
- Send invoice with PDF attached.
- Confirm customer email arrives.
- Open PDF on phone and desktop.
- Open public invoice link.
- Confirm Pay now/payment details show correctly.

## Role test
- Worker cannot open owner dashboard.
- Payroll lands on payroll board.
- Payroll cannot open reports.
- Manager and office admin access only allowed work areas.

## Pass rule
Churvox is launch-ready only when owner, worker and public customer flows pass on phone and desktop.
