# Churvox customer-review readiness

Core promise:
Job done. Admin prepared. Owner approves.

## What customers clearly want

1. Fast setup
Owners want to move from paper/spreadsheets into the app without a long implementation.

2. One daily starting point
They need to see today's jobs, late work, invoices, quotes, and approvals without hunting.

3. Simple mobile worker flow
Workers need job details, time actions, notes, proof/photos, and complete job controls.

4. Completed work to invoice
A completed priced job should become invoice-ready quickly.

5. Customer communication
Quotes, reminders, invoices, and follow-ups should be easy to understand and send.

6. Clear pricing
No surprise add-ons, no confusing sync language, no trap feeling.

7. Human support
Setup help should feel personal and simple.

8. Useful reporting
Owners do not just want numbers; they want to know what needs fixing.

## What Churvox should avoid

- Public build/test/launch wording inside customer pages.
- Overloading Command with every record.
- Making AI sound like it acts without approval.
- Hidden or confusing pricing/add-ons.
- Worker pages showing owner-only tools.
- Public test data or test checklists on the live site.
- Complex automation builder before the core flow works.

## Churvox winning angle

Other apps store the admin.
Churvox prepares the admin and waits for owner approval.

## Whole-site priority order

1. Smart Hub clarity.
2. Worker proof flow.
3. Completed job to invoice-ready.
4. Command approvals.
5. Admin debt and missing info.
6. Support/setup help.
7. Plans/pricing clarity.
8. Mobile polish.
9. Imports from spreadsheets.
10. Customer/public portal safety.

## Manual test rule

Do not add more features until these flows feel clean:
- Client created.
- Worker created.
- Job created and assigned.
- Worker acknowledges, starts, pauses, resumes, adds proof, completes.
- Completed job becomes invoice-ready.
- Command shows prepared admin with approve/edit/park.
- Pricing is clear.
- Support is easy.
- Mobile works.
